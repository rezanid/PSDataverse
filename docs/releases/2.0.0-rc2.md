# PSDataverse 2.0.0-rc2

This release candidate fixes Windows Web Account Manager (WAM) native library
discovery for interactive authentication. It includes the features introduced in
[2.0.0-rc1](2.0.0-rc1.md) and requires PowerShell 7.6 or later.

## Fixes

- Pin the transitive PKCS cryptography dependency to the patched .NET 10.0.13
  version. The test project's XML cryptography dependency is also pinned to
  10.0.13 to clear the release dependency audit.
- Package the x64, x86, and ARM64 WAM native libraries beside the managed
  authentication assemblies so PowerShell can resolve them. This addresses
  `Unable to load DLL 'msalruntime'` and `msalruntime_arm64` failures when using
  `Connect-Dataverse -Interactive` on Windows.
- Verify that all three Windows native libraries are packaged and that the
  library matching the current Windows PowerShell process architecture loads
  successfully during the package smoke test.

## Install

```powershell
Install-PSResource -Name PSDataverse -Version 2.0.0-rc2 -Prerelease
```

Or with PowerShellGet:

```powershell
Install-Module -Name PSDataverse -RequiredVersion 2.0.0-rc2 -AllowPrerelease
```

Start a fresh PowerShell session before testing the updated module so previously
loaded authentication assemblies do not remain in memory.

Review the [migration guide](https://github.com/rezanid/PSDataverse/blob/main/MIGRATION.md)
before upgrading existing 0.x automation. Please report prerelease feedback through
[GitHub Issues](https://github.com/rezanid/PSDataverse/issues).
