# Remove-DataverseRow

## SYNOPSIS

Deletes one Dataverse row.

## SYNTAX

### __AllParameterSets

```
Remove-DataverseRow [-TableSetName] <string> [-Id] <guid> [-IfMatch <string>]
 [-Connection <DataverseConnection>] [-ConnectionName <string>] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Remove-DataverseRow sends DELETE to a row URI. The default If-Match value requires the row to exist. IDs can be supplied through the pipeline.

## EXAMPLES

### Example 1: Delete one account

```powershell
Remove-DataverseRow accounts $accountId
```

Deletes the row after confirmation.

### Example 2: Delete several known rows

```powershell
$ids | Remove-DataverseRow -TableSetName new_projects -Confirm:$false
```

Deletes each supplied ID independently.
