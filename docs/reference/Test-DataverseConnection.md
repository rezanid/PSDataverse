# Test-DataverseConnection

## SYNOPSIS

Tests a Dataverse connection with WhoAmI.

## SYNTAX

### __AllParameterSets

```
Test-DataverseConnection [[-Connection] <DataverseConnection>] [[-ConnectionName] <string>]
 [-Detailed] [<CommonParameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Test-DataverseConnection sends WhoAmI through the selected connection. It returns a Boolean by default or identity, timing, status, and service URL details with Detailed.

## EXAMPLES

### Example 1: Test the default connection

```powershell
Test-DataverseConnection
```

Returns true when WhoAmI succeeds.

### Example 2: Inspect a named connection

```powershell
Test-DataverseConnection -ConnectionName production -Detailed
```

Returns a structured diagnostic result.
