# Set-DataverseRow

## SYNOPSIS

Updates one Dataverse row.

## SYNTAX

### __AllParameterSets

```
Set-DataverseRow [-TableSetName] <string> [-Id] <guid> [-Body] <Object> [-IfMatch <string>]
 [-PassThru] [-Connection <DataverseConnection>] [-ConnectionName <string>] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Set-DataverseRow sends PATCH to one row. By default it requires the row to exist. PassThru requests and emits the updated representation.

## EXAMPLES

### Example 1: Update an account

```powershell
Set-DataverseRow accounts $accountId @{ telephone1 = '+33 1 23 45 67 89' }
```

Updates the telephone number.

### Example 2: Return the updated row

```powershell
$account = Set-DataverseRow accounts $accountId $changes -PassThru
```

Adds Prefer: return=representation and emits the updated row.
