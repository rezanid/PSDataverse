# New-DataverseRow

## SYNOPSIS

Creates one Dataverse row.

## SYNTAX

### __AllParameterSets

```
New-DataverseRow [-TableSetName] <string> [-Body] <Object> [-Connection <DataverseConnection>]
 [-ConnectionName <string>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

New-DataverseRow sends a POST request to a Web API entity set. Body can be a dictionary or PowerShell object and is serialized as JSON.

## EXAMPLES

### Example 1: Create an account

```powershell
New-DataverseRow accounts @{ name = 'Contoso' }
```

Creates one account row.

### Example 2: Capture the response

```powershell
$response = New-DataverseRow new_projects $project
```

Returns the PSDataverse response envelope.
