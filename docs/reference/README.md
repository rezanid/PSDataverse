# PSDataverse command reference

These Markdown topics are the source for the packaged `Get-Help` content.

- [Clear-DataverseTable](Clear-DataverseTable.md) — Starts a Dataverse bulk-delete job that removes every row from one or more tables.
- [Connect-Dataverse](Connect-Dataverse.md) — Authenticates to Dataverse and registers a reusable connection.
- [Disconnect-Dataverse](Disconnect-Dataverse.md) — Disposes one or all registered Dataverse connections.
- [Export-DataverseOptionSet](Export-DataverseOptionSet.md) — Returns English labels and values from Dataverse global option sets.
- [Export-DataverseRows](Export-DataverseRows.md) — Exports Dataverse rows to a CSV or JSON file.
- [Get-DataverseAttributes](Get-DataverseAttributes.md) — Gets attribute metadata for one or more Dataverse tables.
- [Get-DataverseConnection](Get-DataverseConnection.md) — Gets registered Dataverse connections.
- [Get-DataverseRow](Get-DataverseRow.md) — Gets one row by ID or lists rows from a Dataverse table.
- [Get-DataverseTableMetadata](Get-DataverseTableMetadata.md) — Gets Dataverse table metadata by logical or entity-set name.
- [Get-DataverseTableRowCount](Get-DataverseTableRowCount.md) — Counts rows in a Dataverse table.
- [Import-DataverseRows](Import-DataverseRows.md) — Imports CSV or JSON rows using an explicitly selected Dataverse write transport.
- [Invoke-DataverseAction](Invoke-DataverseAction.md) — Invokes a bound or unbound Dataverse Web API action.
- [Invoke-DataverseCreateMultiple](Invoke-DataverseCreateMultiple.md) — Creates homogeneous Dataverse rows using concurrent CreateMultiple chunks.
- [Invoke-DataverseFunction](Invoke-DataverseFunction.md) — Invokes a bound or unbound Dataverse Web API function.
- [Invoke-DataverseRequest](Invoke-DataverseRequest.md) — Sends one or more low-level Dataverse Web API operations with bounded concurrency.
- [Invoke-DataverseUpdateMultiple](Invoke-DataverseUpdateMultiple.md) — Updates homogeneous Dataverse rows using concurrent UpdateMultiple chunks.
- [Invoke-DataverseUpsertMultiple](Invoke-DataverseUpsertMultiple.md) — Creates or updates homogeneous Dataverse rows using concurrent UpsertMultiple chunks.
- [New-DataverseRow](New-DataverseRow.md) — Creates one Dataverse row.
- [New-DataverseTable](New-DataverseTable.md) — Creates a basic custom Dataverse table.
- [Remove-DataverseRow](Remove-DataverseRow.md) — Deletes one Dataverse row.
- [Remove-DataverseTable](Remove-DataverseTable.md) — Deletes a Dataverse table and all of its data.
- [Set-DataverseDefaultConnection](Set-DataverseDefaultConnection.md) — Selects the default registered Dataverse connection.
- [Set-DataverseRow](Set-DataverseRow.md) — Updates one Dataverse row.
- [Test-DataverseBulkOperationSupport](Test-DataverseBulkOperationSupport.md) — Tests whether a Dataverse table supports a multiple-row message.
- [Test-DataverseConnection](Test-DataverseConnection.md) — Tests a Dataverse connection with WhoAmI.
- [Send-DataverseOperation](Send-DataverseOperation.md) — Compatibility alias for `Invoke-DataverseRequest`.
