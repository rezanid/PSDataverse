# Invoke-DataverseFunction

## SYNOPSIS

Invokes a bound or unbound Dataverse Web API function.

## SYNTAX

### __AllParameterSets

```
Invoke-DataverseFunction [-Name] <string> [-Parameters <hashtable>] [-BoundUri <string>]
 [-Connection <DataverseConnection>] [-ConnectionName <string>] [<CommonParameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Invoke-DataverseFunction constructs an OData function call, assigns parameter aliases, sends a GET request, and converts JSON content into PowerShell objects.

## EXAMPLES

### Example 1: Invoke an unbound function

```powershell
Invoke-DataverseFunction -Name WhoAmI
```

Invokes an unbound function with no parameters.

### Example 2: Invoke a function with parameters

```powershell
Invoke-DataverseFunction -Name new_GetScore -Parameters @{ accountId = $accountId }
```

Encodes the parameters as OData aliases.
