# Export-DataverseRows

## SYNOPSIS

Exports Dataverse rows to a CSV or JSON file.

## SYNTAX

### __AllParameterSets

```
Export-DataverseRows [-TableSetName] <string> [-Path] <string> [-Select <string[]>]
 [-Filter <string>] [-Format <string>] [-JsonDepth <int>] [-Connection <DataverseConnection>]
 [-ConnectionName <string>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Export-DataverseRows retrieves all matching pages from an entity set and writes the resulting rows to CSV or JSON. Use Select to reduce payload size and Filter to restrict rows.

## EXAMPLES

### Example 1: Export selected account columns

```powershell
Export-DataverseRows accounts ./accounts.csv -Select name,accountid
```

Retrieves all pages and writes CSV inferred from the extension.

### Example 2: Export filtered rows as JSON

```powershell
Export-DataverseRows contacts ./active.json -Format Json -Filter 'statecode eq 0'
```

Writes active contacts as JSON.
